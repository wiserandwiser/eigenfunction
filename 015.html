QUANTUM · computation — steering waves of probability so wrong answers cancel and right ones add up

A quantum computer doesn’t try every answer at once. That is the popular myth. It sets up interference, the effect from Φ 007, so the waves pointing at wrong answers cancel out and the right answer gets louder. And it has to finish before decoherence (Φ 012) wipes the slate.

01The qubit

Program a qubit with gates

Gates applied—
Chance of 0 · 1—
Last 200 readings—

A classical bit is 0 or 1. A qubit is an arrow on a sphere: north is 0, south is 1, and everywhere else is a superposition. Read it and you always get a plain 0 or 1, with odds set by how far north or south the arrow points.

Gates are rotations. X flips the arrow over, a quantum NOT. H (Hadamard) swings 0 onto the equator, an even superposition. Z, S and T spin the arrow around the vertical axis. They change the phase, which leaves the odds of 0 and 1 untouched.

So why bother with phase? Try H, then Z, then H. The first H makes a 50/50 superposition, and Z changes nothing you could measure. Yet the final H now gives a certain 1 instead of a certain 0. The hidden phase decided the outcome through interference. Every quantum algorithm is built from tricks like this.

Try thisReset, then try H, H: back to 0. Reset, then H, Z, H: now 1. Measure after each to check.
The math
|ψ⟩ = α|0⟩ + β|1⟩,  H = 1√2[1  1 ; 1 −1]

The odds are |α|² and |β|². The gates: X swaps the amplitudes; Z multiplies β by −1; S by i; T by eiπ/4. The identity HZH = X shows how a phase flip becomes a bit flip through interference.

02An algorithm

Grover’s search: amplify the right answer

Rounds0

Best number of rounds—
Classical average guesses—

Searching an unsorted list of N items for one marked item takes a classical computer about N/2 tries on average. Lov Grover found in 1996 that a quantum computer needs only about √N rounds.

Start with every answer equally likely: all the bars the same height. Each round has two moves. First the oracle marks the right answer by flipping its amplitude upside down, a phase change you couldn’t see by measuring. Then a flip about the average reflects every bar through the mean. The marked bar, now far below the average, bounces up high above it, and every other bar shrinks a little.

Repeat, and the right answer’s bar grows round by round, through interference rather than luck. For 16 items, 3 rounds give a 96% chance of reading it. Do too many rounds and it overshoots and shrinks again, like pushing a swing at the wrong moment.

Try thisStep through one round slowly, mark then flip, to see the mechanism. Then run full rounds and stop at the best number. Push past it to see the overshoot.
The math
kbest ≈ π4√N,  P(k) = sin²((2k + 1)θ), sin θ = 1/√N

Each round rotates the state by 2θ towards the answer in a two-dimensional plane. The oracle is the reflection ax → −ax on the marked item, and the diffusion step is ai → 2ā − ai. The quadratic speed-up is proven optimal for unstructured search.

03The hard part

Error correction and the threshold

Logical error rate—
Qubits per logical qubit—
Bigger code helps?—

Real qubits make mistakes, roughly one in every few hundred to a few thousand operations. Big algorithms need billions of operations, so errors must be fixed on the fly. But you can’t copy a qubit to back it up, and looking at it destroys it.

The answer is quantum error correction. Spread one logical qubit across many physical ones, and check only shared properties, like “do these two agree?”. That reveals errors without reading the data. In the leading design, the surface code, a code of size d uses about 2d² physical qubits.

There is a catch, called the threshold. More qubits means more places for errors. If the hardware is good enough, below roughly 1% error per step, each increase in size cuts the logical error dramatically. Above it, bigger codes make things worse. In late 2024 Google’s Willow chip showed the logical error falling by about half with each step up in code size, clear evidence of working below threshold.

That is the road to useful machines, including the ones that could break today’s encryption. Peter Shor’s 1994 algorithm factors large numbers, and a 2025 estimate put breaking RSA-2048 at under a million noisy qubits running for about a week. Φ 016 picks up that thread.

Try thisSet the physical error just below the threshold and step the code size up: the logical error plunges. Then move above the threshold and watch bigger codes lose.
The math
pL ≈ A (p / pth)(d+1)/2

The standard approximate scaling for a distance-d surface code, with pth ≈ 1% and A ≈ 0.1. A code of distance d corrects up to ⌊(d − 1)/2⌋ errors per round, so failure needs about (d + 1)/2 errors, hence the exponent. Qubit count: d² data qubits plus d² − 1 check qubits.

Observations

What quantum computers are for

Chemistry

Simulating molecules

Molecules are quantum systems, and classical computers struggle to simulate them exactly. Designing catalysts, batteries and drugs is the application physicists expect to pay off first.

Cryptography

Shor’s algorithm

Factoring large numbers underpins RSA encryption. Shor’s algorithm does it exponentially faster than any known classical method, which is why the world is moving to new “post-quantum” codes now.

Hardware

Many competing designs

Superconducting circuits, trapped ions, neutral atoms held by lasers, photons and spin qubits in silicon are all in the race. Each trades speed, quality and how easily it scales.

Reality check

Not faster at everything

Quantum computers won’t speed up email, video or most everyday code. They help only problems with structure that interference can exploit, and even Grover gives just a square-root gain.

Note to self

A quantum computer doesn’t try every answer at once. It choreographs interference so the right answer rings loudest, and it fights errors fast enough to finish.
